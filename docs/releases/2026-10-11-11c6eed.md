## Notes

- Change set was `package.json` / `package-lock.json` only — no `app/db/schema.ts`
  or `migrations/` changes, so no pre-deploy `pg_dump` was required.
- **drizzle-kit caveat:** `11c6eed` bumps `drizzle-kit` 0.31.10 → 0.31.11. The
  `migrate` container logged a spurious prompt to add the already-present
  `finance_account_balance_snapshots_account_date_unique` constraint, then
  aborted with `Error: Interactive prompts require a TTY terminal`. It still
  reported **exit 0**, so the Compose `service_completed_successfully` gate and
  `release.sh verify`'s "migrate exited 0" check both passed.
- The abort happened in drizzle-kit's pre-execution `pgSuggestions` phase, so no
  statements ran. The database already has that unique constraint (12 rows, 12
  distinct `(account_id, balance_date)` pairs), i.e. the schema was already in
  sync and production is correct.
- Latent risk to watch: a future schema-changing release could be silently
  skipped if drizzle-kit hits a non-TTY prompt and still exits 0. Treat
  "migrate exited 0" as necessary but not sufficient — inspect the migrate logs.

## Follow-up

This release also broke browser form submissions: React Router was bumped
8.3.0 → 8.4.0, whose new CSRF guard rejected the `https` Origin sent by
browsers against the app's `http` request URL behind Traefik. Fixed forward in
`sha-2c47912` (see `2026-10-11-2c47912.md`).
